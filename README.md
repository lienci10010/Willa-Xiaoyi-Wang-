# Daisy 个人网站

打开 `index.html` 即可查看，无需安装依赖或联网加载字体、脚本。也可以将整个文件夹上传到任意静态网站托管服务。

## 内容与修改
- `index.html`：页面结构、公司、职务、地址与联系链接。
- `style.css`：样式与手机适配。
- `script.js`：简体中文、英文、繁体中文文案及画廊交互。
- `assets/`：八张用户提供的照片转换为网页 JPG，第一张用于主页。
- 客户满意度和合作伙伴评价为明确标注的示例模板；未虚构分数、真实客户姓名或公司背书。正式使用时请替换为获授权的真实资料。
- 公司名称按照提供的信息写为 Rackspace Technology；网站链接按照提供的信息指向 Zenlayer，两项分别显示。
- 业务介绍是根据本次网站主题拟写的介绍文案，请按实际业务范围调整。
- Teams 按钮打开提供账号的聊天链接；访客可能需要 Teams 登录及组织权限。邮件按钮调用访客默认邮件程序。
- 未部署线上网站，此压缩包为完整可运行静态源码。

## 语言切换
右上角选择语言，页面文案及画廊标签同步切换。在浏览器允许的情况下保留语言选择。

## 图片查看
点击画廊照片放大，点击关闭按钮、背景或按 Escape 关闭。
